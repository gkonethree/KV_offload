Which tokens does PQ attention actually read?

Every decode step, PQ scores all cached keys and each KV head keeps a sink window, a local window, and its top-k of the middle. This trace records that choice for every step, layer and KV head, then asks how much of each 16-token page a page-granular fetch would move for nothing.

Prefetch simulator

Replays this trace with every middle page on the CPU and a per-layer GPU cache that holds C pages. Pages a layer needs but the cache lacks must be streamed in. A prefetcher guesses them before the layer runs, so a correct guess arrives in the background (hidden) and a miss stalls the GPU (exposed). Wrong guesses cost transfer only.
